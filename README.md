# YMM4再生タイミング調整プラグイン

YMM4のプレビュー再生のタイミングを調整し、フレームレートの改善を図るプラグインです。動作確認済みのバージョンは YMM4 4.57.0.0 です。
プラグインの仕組みとYMM4への変更箇所は、[開発者向けドキュメント](docs/README.md)を参照してください。

## インストール

`YMM4PlaybackTimingPlugin.ymme`をダウンロードしてインストールします。導入後は自動で動作し、設定は不要です。

## プレビュー再生診断

YMM4の「ツール」から「プレビュー再生診断」を開くと、全般・プロジェクト・プレビュー・モニターの情報を確認できます。

「計測」をオンにすると、再生中の描画FPS、送信FPS、累計フレーム数、最大送信間隔、送信失敗数を集計します。計測は初期状態でオフです。パネルを閉じると計測を停止します。

送信FPSは、プレビューへの提示を要求した頻度です。モニターの色形式・ビット深度はWindowsの報告値です。「結果をコピー」には、デバイスパスや取得エラーなどの診断情報も含まれます。
